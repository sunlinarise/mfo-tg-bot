# Перенос Telegram-бота с Puzzlebot на botost.ru

Бот партнёрской программы МФО. Пользователь жмёт `/start`, бот присылает
картинку с текстом «Нужны деньги? Подберите предложение для своей страны…»
и две кнопки:

- **РОССИЯ** → mini app `https://zaim-deneg.ru/`
- **КАЗАХСТАН** → mini app `https://oformit-mikrokrediti-bistro.zaimstore.com/`

Дожим через 10 минут пока не реализован — для него нужна база пользователей.

Работает на `main.py` + `requirements.txt`, в корне репозитория → botost.ru
соберёт и запустит сам.

## Что нужно перед деплоем

1. **Токен бота.** Уже есть. На botost.ru он передаётся в контейнер как
   `BOT_TOKEN` — отдельно в код его класть не нужно.
2. **Ваш Telegram ID для `/broadcast`.** Узнать: напишите [@userinfobot](https://t.me/userinfobot),
   он пришлёт число вида `123456789`.
3. **Картинка приветствия** — уже лежит в `assets/start.png`.

## Переменные окружения на botost.ru

| Переменная | Обязательно | Пример |
|---|---|---|
| `BROADCAST_ADMIN_ID` | да | `123456789` |
| `SITE_RU_URL` | нет | по умолчанию `https://zaim-deneg.ru/` |
| `SITE_KZ_URL` | нет | по умолчанию `https://oformit-mikrokrediti-bistro.zaimstore.com/` |
| `START_TEXT` | нет | текст приветствия |
| `START_IMAGE` | нет | `assets/start.png` |
| `BOT_TOKEN` | ставит платформа | — |

Ссылки стран уже зашиты по умолчанию, так что на botost.ru достаточно
добавить только `BROADCAST_ADMIN_ID`.

## Деплой на botost.ru

1. Создайте на GitHub пустой репозиторий.
2. Загрузите туда файлы из этой папки:
   ```bash
   cd puzzlebot-mfo-bot
   git init
   git add .
   git commit -m "MFO bot for botost"
   git remote add origin https://github.com/<вы>/mfo-bot.git
   git push -u origin main
   ```
3. На botost.ru: **Создать бота** → платформа **Telegram** → укажите токен,
   GitHub URL и ветку `main`.
4. Добавьте переменные окружения (таблица выше) и нажмите **Создать/Деплой**.
5. Смотрите логи. Ожидаемо: `Запуск polling…` и никаких `Conflict`.

Важно: домен **не нужен**. Бот работает через long polling, что покрывает
бесплатный тариф (1 бот, 256 МБ RAM — этого боту с запасом хватает).

## Проверка

- [ ] В Telegram `/start` → пришла картинка с подписью и две кнопки:
      РОССИЯ и КАЗАХСТАН (одна под другой).
- [ ] Кнопки открывают mini app (проверьте на телефоне, в приложении, не в
      веб-версии).
- [ ] `/broadcast Тест` с вашего аккаунта → пришло «✅ Рассылка завершена».
- [ ] `/broadcast Тест` с чужого аккаунта → «⛔ Эта команда доступна только
      администратору».

## Что дальше (пока не делали, по вашему решению)

- **База пользователей** (`PostgreSQL` на botost.ru или SQLite в `/app/data`).
  Без неё рассылка и дожим живут только пока процесс не перезапустился.
- **Дожим через 10 минут** — как в конструкторе: картинка + текст
  «Шанс на одобрение прямо сейчас максимальный…» и те же две кнопки.
  Добавим после подключения базы.
- При переезде с Puzzlebot: убедитесь, что в Puzzlebot бот **остановлен**,
  иначе оба процесса будут читать один токен и получите
  `Conflict: terminated by other getUpdates request`.
